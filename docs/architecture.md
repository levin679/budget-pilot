# Архитектура BudgetPilot

## Слои

- `FinanceStore` — единый state container и бизнес-операции.
- `CsvService` — отдельный сервис сериализации и разбора CSV, покрытый тестами.
- `features/*` — ленивые страницы пользовательских сценариев.
- `BrowserStorageService` — инфраструктурная абстракция persistence.

## Производные данные

Доходы, расходы, cashflow, saving rate, распределение категорий и временной ряд не хранятся отдельно. Они вычисляются через `computed`, поэтому не могут рассинхронизироваться с исходными операциями.

## Production roadmap

Backend API, аутентификация, шифрование чувствительных данных, серверная синхронизация, recurring transactions, Open Banking import, полноценная локализация и e2e.
