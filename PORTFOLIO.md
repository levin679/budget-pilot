# Описание для портфолио

**BudgetPilot — клиентское приложение для анализа личных финансов.**

Я реализовал типизированную модель операций, вычисляемые показатели доходов и расходов, месячные бюджеты, цели накоплений и CSV-импорт/экспорт. Графики построены на CSS, поэтому приложение не зависит от тяжёлой chart-библиотеки. Для состояния использованы Angular Signals, для форм — Reactive Forms.

**Практическая направленность:** пользователь может вести операции локально, контролировать лимиты, видеть норму сбережений и выгружать данные. Архитектура допускает замену localStorage на банковский/серверный API.

**Что демонстрирует:** Angular, TypeScript, Signals, формы, обработка файлов, парсинг CSV, агрегация данных, адаптивная аналитическая верстка, тестирование утилит.
